Solving the Joltage Counter Puzzle

Press Space or → to continue

The Problem (Part 2)

Each machine has numeric counters tracking joltage levels, all initially set to zero.

Joltage requirements like {3,5,4,7} mean the goal is to configure the first counter to 3, the second to 5, the third to 4, and the fourth to 7.

Each button press increases the listed counters by 1. A button like (1,3) means pressing it increases the 2nd and 4th counters by 1.

Find the fewest total button presses to reach all target values across all machines.

# Example machine:
[.##.] (3) (1,3) (2) (2,3) (0,2) (0,1) {3,5,4,7}

# 6 buttons, 4 counters, targets: 3, 5, 4, 7

Spotting the Pattern

What clues in the problem hint at the solution approach?

Each counter must reach its exact target value. Find the minimum total presses.

The Solution: Gaussian Elimination

A classic algorithm (from 1810!) that systematically eliminates variables until we can express some in terms of others.

The Key Insight

After elimination, some variables become "free" — we can choose their values.

The remaining variables are determined by our choices.

We only need to search over the free variables, not all possible combinations!

The Algorithm in Action

GaussianSolver.java (Pseudocode)
1 // === PHASE 1: BUILD MATRIX ===
2 for each counter c:
3   for each button b:
4     A[c][b] = 1 if button b affects counter c
5
6 // === PHASE 2: GAUSSIAN ELIMINATION ===
7 for v = 0 to numVars - 1:
8   // Find row with non-zero coeff for x_v
9   pivotRow = -1
10   for row = 0 to numEquations:
11     if |A[row][v]| > EPS:
12       pivotRow = row; break
13
14   if pivotRow == -1:
15     freeFlags[v] = true // No pivot → FREE!
16     continue
17
18   // Extract: solve pivot row for x_v
19   pivot = -A[pivotRow][v]
20   varConst[v] = b[pivotRow] / pivot
21   for i = 0 to numVars:
22     varCoeffs[v][i] = A[pivotRow][i] / pivot
23   freeFlags[v] = false // v is determined
24
25   // Substitute x_v into all other equations
26   for each equation j:
27     coeff = A[j][v]
28     A[j][v] = 0
29     for i: A[j][i] += coeff * varCoeffs[v][i]
30     b[j] += coeff * varConst[v]
31
32 // === PHASE 3: ENUMERATE FREE VARS ===
33 freeVars = [v where freeFlags[v] == true]
34 best = INFINITY
35
36 for each combination of freeVars (0 to upperBound):
37   // Compute dependent vars from expressions
38   for i = numVars-1 down to 0:
39     if not freeFlags[i]:
40       x[i] = varConst[i] + Σ(varCoeffs[i][j]*x[j])
41
42   // Validate: must be non-negative integer
43   if x[i] < 0: skip // invalid
44   if x[i] != round(x[i]): skip // not integer
45
46   total = sum(x)
47   best = min(best, total)
48
49 return best

Key Takeaways

  • Recognize patterns — "variables", "linear", "constraints", "minimize" → Linear Algebra
  • Use the right tool — Gaussian Elimination is centuries old and battle-tested
  • Free variables are the key — They reduce an infinite search to a finite one
  • Constraints help — Upper bounds from targets prune the search space

The best solutions come from recognizing
what kind of problem you're really solving.
