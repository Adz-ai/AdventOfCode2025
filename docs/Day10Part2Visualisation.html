2 The Math Behind It

This puzzle is actually a system of linear equations! Each button press count becomes a variable (x0, x1, ...), and we need to find values that satisfy all counter targets.

A (which buttons affect which counters) × x (how many times to press each) = b (target values)

3 Gaussian Elimination: Step by Step

We solve this by eliminating variables one at a time, expressing each variable in terms of others until we find "free" variables we can choose ourselves.

4 Finding the Minimum

With free variables identified, we enumerate possible values and check which combinations give valid solutions (non-negative integers). The solution with the smallest total wins!
